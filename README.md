# Arquivos de teste

Este repositório é utilizado para armazenar e servir arquivos públicos, ativos de teste, assets de projetos e dados temporários/experimentais.

## 📌 Finalidade
- **Hospedagem de Ativos:** Imagens, documentos, JSONs e arquivos estáticos para consumo em APIs ou aplicações.
- **Ambiente de Testes:** Validação de links diretos (CDN/RAW) para testes de requisição e integração.
- **Acesso Público:** Disponibilização rápida de recursos sem restrições de autenticação.

## ⚠️ AVISO
> **Atenção:** Este repositório é totalmente **público**. Nunca envie chaves de API, senhas, tokens de acesso, credenciais ou qualquer informação sensível/pessoal para este local.
